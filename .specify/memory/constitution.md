# Timeline Map Constitution

## Core Principles

### I. Non-AI Design Mandate
All design assets MUST be hand-crafted, manually modeled, or drawn by human artists. Generative AI tools MUST NOT be used for creating final visual assets. This is to maintain a unique, authentic, and deeply human-crafted historical aesthetic.

### II. Spatial and Temporal Immersion
The core user experience MUST seamlessly blend 3D spatial navigation (e.g., similar to Google Maps in 3D mode) with temporal navigation (a timeline slider). Users should be able to drag the map to move spatially and slide the timeline to move temporally.

### III. Dual-Era Visual Transformation
The map MUST support dynamic, distinct visual transformations based on the selected time period.
- **Present Day:** Clean, modern isometric 3D rendering.
- **Past (Historical):** Antique, old-world sketch style (hồi cổ, xưa cũ).

### IV. Interactive Exploration & AR
The application MUST encourage active exploration. It should include interactive elements on the map and support AR (Augmented Reality) camera views to overlay historical contexts onto real-world locations.

### V. Authenticity First
Historical accuracy and cultural authenticity MUST be prioritized in UI/UX decisions and content curation. The design should evoke a genuine sense of history rather than generic gamification.

## Design and Asset Constraints

- **Map Rendering:** Must support pulling up a flat map into a 3D model.
- **UI Elements:** The main interface should include a prominent timeline slider at the bottom, allowing seamless switching between eras (e.g., 1972 vs. Present).
- **AR Camera:** The AR view must overlay historical structures and elements (e.g., hidden bunker entrances, soldiers) onto the user's real-world camera feed.

## Development Workflow

- **Asset Review:** All 3D models and hand-drawn sketches require manual review for both cultural authenticity and compliance with the non-AI design mandate.
- **Prototyping:** UI iterations must follow the provided sample UI structure (Timeline Map, dual-era split, AR camera).

## Governance

- The Constitution supersedes all other design practices.
- The Non-AI Design Mandate is strictly enforced; any deviation or exception requires explicit, documented approval from the project lead.
- All Pull Requests must verify that visual assets were not generated by AI.
